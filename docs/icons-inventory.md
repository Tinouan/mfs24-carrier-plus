## Principe Map

Chaque factory sur la map affiche l'icône du **produit en cours de fabrication**.
- Factory idle → icône factory générique
- Factory producing → icône de l'item result de la recette en cours
- Taille suggérée : 32×32 ou 48×48 px

## Notes d'implémentation

- Dans `seed.json`, chaque item a un champ `icon` qui contient actuellement un code 2-3 lettres
- Quand les icônes visuelles seront prêtes, on ajoutera un champ `icon_path` pointant vers le fichier
- Le renderer de la map utilisera `icon_path` si disponible, sinon fallback sur le code texte
- Coherent GT supporte les images SVG et PNG inline
